You need a **username** and a **password**. The club manager gives them to you.

:::example
In this guide we use the username **demo**. Type your own username.
:::

:::step Open the app
Double-click the app icon on the desktop, or open the club's link in the browser.
:::

:::step Type the username
Click inside the first box, then type the username.
::figure login ring=login-username
:::

:::step Type the password
Click inside the second box, then type the password. To see what you typed, click the eye icon.
::figure login ring=login-password
:::

:::step Click “Log in”
The “Dashboard” page appears. You are logged in!
::figure login ring=login-submit zoom=login-submit
:::

:::warning
Forgot your password? Ask the club manager to set a new password for you.
:::
