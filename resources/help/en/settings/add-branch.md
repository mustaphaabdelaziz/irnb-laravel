Each sports branch has a code, a name, its categories and its safe. Each player gets a membership number that starts with the code of their branch.

:::example
The club opens a new branch named “كرة اليد” (handball), with the code HB.
:::

:::step Open the “Branches” page
On a phone, first open the menu with the ☰ button. In the menu, click “Branches” under “App Configuration”. You don't see it? Click “App Configuration” to show it. You need the “View” right in “Branches”.
::figure set-branch-list ring=nav-branches
:::

:::step Type the “Name” and “Branch code”
In “Name”, type: كرة اليد. In “Branch code”, type: HB. The code has 2 to 6 capital Latin letters. Leave it empty and the app suggests a code from the Latin letters of the name. If the name has no Latin letters, the app asks you to type the code.
::figure set-branch-add ring=branch-name,branch-code
:::

:::step Click “Add”
The message “Branch created successfully.” appears. The branch appears in the list under the form. The app creates a safe for it alone, named “كرة اليد safe”. You need the “Add” right in “Branches”.
::figure set-branch-add ring=branch-add zoom=branch-add
:::

:::step Click the pencil button of the branch
In the branch's row, click the pencil button. When you hover over it, its name “Edit” appears. The branch page opens. The picture shows the “Football” branch as an example.
::figure set-branch-rows ring=branch-edit zoom=branch-edit
:::

:::step Open the “Categories” tab
Click “Categories”, next to “General”. This is where you add the branch's categories. The article “How do I add a category in a branch” explains it.
::figure set-branch-detail ring=branch-tab-categories zoom=branch-tab-categories
:::

:::step Set the main branch if needed
In the branch list, click the flag button of the branch you want. When you hover over it, its name “Set as main branch” appears. The message “Main branch set.” appears. You don't see the button on a branch? It is the main branch now. The main branch gives no privilege. For a player registered in several branches, their registration in the main branch becomes the primary one. And the “Categories” page and the attendance pages open on the main branch first. The button needs the “Edit” right in “Branches”.
::figure set-branch-rows ring=branch-set-main zoom=branch-set-main
:::

:::tip
The “Members” button of each branch shows the players registered in it. But you usually add players from the player's page.
:::
