Document types are shared by all the club's branches. But you choose the branches that require each type from their players. So a swimmer is not asked for what concerns football.

:::example
The football federation requires “رخصة الاتحاد” (federation licence) every season. The club creates it and requires it from football players only.
:::

:::step Open the “Document types” page
On a phone, first open the menu with the ☰ button. In the menu, click “Document types” under “App Configuration”. You don't see it? Click “App Configuration” to show it. You need the “View” right in “Document types”.
::figure set-doc-types ring=nav-document-types
:::

:::step Click the “New document type” button
At the top of the page, click the button with the + sign. When you hover over it, its name “New document type” appears. A window opens. You need the “Add” right in “Document types”.
::figure set-doc-types ring=doc-add zoom=doc-add
:::

:::step Type the “Name”
In “Name”, type: رخصة الاتحاد.
::figure set-doc-type-name ring=doc-name
:::

:::step Choose the “Validity”
In “Validity”, choose “One season”. The licence stays valid until the end of the season.
::figure set-doc-type-name ring=doc-validity
:::

:::step Leave “Football” alone in “Branches”
In the window, all branches start ticked. Click the box next to “Swimming” to untick it. “Football” stays alone. When you edit an existing type, if you untick a branch that has records, the app asks for a second confirmation.
::figure set-doc-type-name ring=doc-branch-1 zoom=doc-branch-1
:::

:::step Tick “Required”
Click the box next to “Required”. A player who does not hand it in has an incomplete file.
::figure set-doc-type-branches ring=doc-required zoom=doc-required
:::

:::step Click “Save”
The message “Document type created.” appears. The type appears in the table. In the “Branches” column, only “Football” shows.
::figure set-doc-type-form ring=doc-save zoom=doc-save
:::

:::tip
The “Copies” box asks for several copies of the document, such as 4 photos. Then the player's file counts the copies received.
:::
