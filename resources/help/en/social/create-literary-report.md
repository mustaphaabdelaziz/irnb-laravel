The literary report is a document that sums up the club's activity over a period. You create it here with a title and a period. Then you prepare its sections and export it as PDF.

:::example
The list holds the report “التقرير الأدبي للموسم 2026/2027” (literary report for the 2026/2027 season). Next to it we create “التقرير الأدبي — نصف الموسم” (literary report — mid-season), from the start of the season to the last day of February.
:::

:::step Open the “Literary report” page
On a phone, first open the menu with the ☰ button. In the menu, click “Literary report” under “Social activities”. The new report form shows, with the list of reports under it.
::figure soc-create-literary-report-list ring=nav-literary-reports
:::

:::step Type the “Report title”
Type: التقرير الأدبي — نصف الموسم. An empty title is not accepted. You need the “Add” permission for “Literary report”. You don't see the form? You don't have this permission.
::figure soc-create-literary-report-form ring=lit-title
:::

:::step Choose the period in “From” and “To”
The app suggests the whole current season. Keep “From” at the start of the season. In “To”, type the last day of February. “To” must be on the same day as “From” or after it.
::figure soc-create-literary-report-form ring=lit-from,lit-to
:::

:::step Click “New report”
The message “Literary report created” shows. If you have the “Edit” permission, the new report opens straight away. If not, you go back to the list, and the report shows in it as a new row.
::figure soc-create-literary-report-form ring=lit-new zoom=lit-new
:::

:::step Use the row's buttons in the list
To open the report, click its title, or the pencil button. Its name, “Edit”, shows when you hover the mouse over it. Both need the “Edit” permission. “Export PDF” needs the “View” permission. The bin button, named “Delete”, needs the “Delete” permission.
::figure soc-create-literary-report-list ring=lit-open-1,lit-edit-1,lit-pdf-1,lit-delete-1
:::

:::tip
An activity joins the report if its “Start date” falls inside the report's period. “زيارة شهرية لدار المسنين” (monthly visit to the retirement home) lasts weeks: it counts once, on its start day. Several reports can cover the same period, each with its own title, period and texts.
:::
