Chaque membre du conseil a un rôle, comme « Président » ou « Trésorier ». Il peut aussi siéger dans une commission. Vous ajoutez les rôles et les commissions une seule fois, puis vous les choisissez dans la page « Membres du conseil ».

:::example
Le club ajoute le rôle « مستشار » (conseiller) au niveau « Bureau ». Puis il ajoute la commission « لجنة الشباب » (commission des jeunes).
:::

:::step Ouvrez la page « Rôles du bureau »
Sur un téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Rôles du bureau » sous « Paramétrage ». Vous ne la voyez pas ? Cliquez sur « Paramétrage » pour l'afficher. Le tableau montre chaque rôle. La colonne « Membres du conseil » compte les membres actifs qui ont ce rôle dans le mandat actuel (les anciens ne comptent pas).
::figure board-roles-committees-roles ring=nav-board-roles
:::

:::step Tapez le « Nom » et choisissez « Niveau (organigramme) » et « Ordre »
Dans « Nom », tapez : مستشار. Dans « Niveau (organigramme) », choisissez : Bureau. Le niveau fixe la place du rôle dans l'organigramme. « Sommet (président) » est sur la première rangée, « Bureau » sur la deuxième. Le niveau « Membre » n'a pas de case : la personne apparaît dans sa commission, ou sous « Autres membres ». Dans « Ordre », tapez : 5. Le plus petit nombre s'affiche en premier. Vous ne voyez pas les champs ? Il vous faut la permission « Ajouter » sur « Rôles du bureau ».
::figure board-roles-committees-role-typed ring=brole-name,brole-level,brole-order
:::

:::step Cliquez sur « Ajouter »
Le message « Rôle créé avec succès. » s'affiche. Le rôle apparaît dans le tableau. Dans l'organigramme, une case vide apparaît pour lui sur la rangée du bureau.
::figure board-roles-committees-role-typed ring=brole-add zoom=brole-add
:::

:::step Corrigez le nom d'un rôle avec le bouton crayon
Par exemple, vous voulez que « Secrétaire général » devienne « Secrétaire ». Sur sa ligne, cliquez sur le bouton crayon. Passez la souris dessus : son nom « Modifier » s'affiche. Un champ s'ouvre avec le nom tel que vous le lisez. Corrigez-le, puis cliquez sur « Enregistrer » sur la même ligne. Le message « Rôle mis à jour avec succès. » s'affiche. Les membres gardent leur rôle, sous le nouveau nom. Le bouton demande la permission « Modifier » sur « Rôles du bureau ».
::figure board-roles-committees-role-rows ring=brole-edit-secretary zoom=brole-edit-secretary
::figure board-roles-committees-role-edit ring=brole-edit-name,brole-edit-save
:::

:::step Ouvrez la page « Commissions »
Sur un téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Commissions » sous « Paramétrage ». Elle se trouve sous « Rôles du bureau ». Il vous faut la permission « Voir » sur « Commissions ». Cette liste a ses propres permissions.
::figure board-roles-committees-committees ring=nav-board-committees
:::

:::step Tapez le nom de la commission et l'« Ordre »
Dans « Nom », tapez : لجنة الشباب. Dans « Ordre », tapez : 4. Le plus petit nombre s'affiche en premier dans l'organigramme. L'application refuse le nom d'une commission qui existe déjà. Vous ne voyez pas les champs ? Il vous faut la permission « Ajouter » sur « Commissions ».
::figure board-roles-committees-committee-typed ring=bcom-name,bcom-order
:::

:::step Cliquez sur « Ajouter »
Le message « Commission ajoutée. » s'affiche. La commission apparaît dans le tableau. Dans l'organigramme, ses cases vides apparaissent : « Président », deux cases « Vice-président de commission » et « Ajouter un membre ».
::figure board-roles-committees-committee-typed ring=bcom-add zoom=bcom-add
:::

:::tip
Un rôle ou une commission utilisé dans un mandat, même ancien, ne peut pas être supprimé. Le nombre dans le tableau peut être 0, car il ne compte que les actifs du mandat actuel. Le bouton corbeille est alors inactif. Passez la souris dessus : « Rôle attribué à des membres » ou « Commission avec membres » s'affiche. Il vous faut la permission « Supprimer » pour voir ce bouton.
:::
