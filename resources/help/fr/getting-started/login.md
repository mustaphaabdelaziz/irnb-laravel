Il vous faut un **nom d'utilisateur** et un **mot de passe**. Le responsable du club vous les donne.

:::example
Dans ce guide, nous utilisons le nom d'utilisateur **demo**. Tapez votre propre nom d'utilisateur.
:::

:::step Ouvrez l'application
Double-cliquez sur l'icône de l'application sur le bureau, ou ouvrez le lien du club dans le navigateur.
:::

:::step Tapez le nom d'utilisateur
Cliquez dans la première zone, puis tapez le nom d'utilisateur.
::figure login ring=login-username
:::

:::step Tapez le mot de passe
Cliquez dans la deuxième zone, puis tapez le mot de passe. Pour voir ce que vous avez tapé, cliquez sur l'icône en forme d'œil.
::figure login ring=login-password
:::

:::step Cliquez sur « Se connecter »
La page « Tableau de bord » s'affiche. Vous êtes connecté !
::figure login ring=login-submit zoom=login-submit
:::

:::warning
Mot de passe oublié ? Demandez au responsable du club de vous mettre un nouveau mot de passe.
:::
