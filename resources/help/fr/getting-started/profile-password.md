Il vous faut le mot de passe que vous utilisez maintenant. Si vous l'avez oublié, demandez un nouveau mot de passe au responsable du club.

:::example
Dans ce guide, l'utilisateur **كريم** de **Club Exemple** change son mot de passe.
:::

:::step Ouvrez la page « Profil »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. En bas du menu, cliquez sur votre nom. La page « Profil » s'affiche.
::figure app-dashboard ring=sidebar-profile
:::

:::step Descendez jusqu'à la partie « Modifier le mot de passe »
Tournez la molette de la souris vers vous, ou glissez deux doigts sur le pavé tactile, pour descendre dans la page. Sur téléphone, faites glisser l'écran vers le haut avec le doigt. Arrêtez-vous à la partie « Modifier le mot de passe ».
::figure profile ring=password-form
:::

:::step Tapez l'ancien mot de passe, puis le nouveau
Tapez votre mot de passe actuel dans la zone « Mot de passe actuel ». Tapez le nouveau dans la zone « Nouveau mot de passe ». Tapez-le une deuxième fois dans la zone « Confirmer le mot de passe ». Il doit faire 8 caractères ou plus.
::figure profile ring=password-current,password-new,password-confirm
:::

:::step Cliquez sur « Enregistrer »
Cliquez sur le bouton « Enregistrer » juste sous ces zones. Le message « Enregistré. » s'affiche. La prochaine fois, connectez-vous avec le nouveau mot de passe.
::figure profile ring=password-save zoom=password-save
:::

:::warning
N'utilisez pas votre nom, votre date de naissance ou le nom du club. Choisissez un mot de passe que vous seul connaissez, et ne le donnez à personne.
:::
