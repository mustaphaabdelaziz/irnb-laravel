Toutes les informations du joueur se changent depuis une seule page : « Modifier le joueur ».

:::example
Dans la fiche de **أحمد بن علي**, le grand-père est écrit « طاهر ». Le bon nom est « الطاهر ».
:::

:::step Ouvrez la page du joueur
Sur la page « Joueurs », cliquez sur le nom du joueur. Sa page s'ouvre. Vous ne le trouvez pas ? Lisez « Comment rechercher un joueur ».
::figure players-filtered ring=player-row-first
:::

:::step Cliquez sur le bouton « Modifier le joueur »
Le bouton est à droite de la page. Sur téléphone, il se trouve sous la carte « Informations de base ». Cliquez sur le bouton marqué d'un crayon. Quand vous posez la souris dessus, son nom « Modifier le joueur » apparaît. La page « Modifier le joueur » s'ouvre.
::figure player-show ring=player-edit zoom=player-edit
:::

:::step Corrigez le champ
Cliquez dans le champ « Grand-père ». Effacez « طاهر » et tapez « الطاهر ».
::figure player-edit ring=player-grandfather
:::

:::step Cliquez sur « Enregistrer les modifications »
Le bouton est en bas de la page. Pour y descendre, tournez la molette de la souris vers vous, ou glissez deux doigts sur le pavé tactile. Sur téléphone, faites glisser l'écran vers le haut avec le doigt. Cliquez sur « Enregistrer les modifications ». Vous revenez sur la page du joueur, avec le message « Joueur mis à jour avec succès. ».
::figure player-edit-bottom ring=player-save zoom=player-save
:::

:::tip
Vous avez changé d'avis ? Cliquez sur « Annuler » à côté de « Enregistrer les modifications » : rien n'est enregistré.
:::

:::warning
Le nouveau nom apparaît sur toutes les pages de l'application. Si le joueur est membre du « Bureau du club », son nom y change aussi.
:::
