Chaque section sportive a un code, un nom, ses catégories et son coffre. Chaque joueur reçoit un numéro d'adhésion qui commence par le code de sa section.

:::example
Le club ouvre une nouvelle section nommée « كرة اليد » (handball), avec le code HB.
:::

:::step Ouvrez la page « Sections »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Sections » sous « Paramétrage ». Vous ne la voyez pas ? Cliquez sur « Paramétrage » pour l'afficher. Il vous faut le droit « Voir » dans « Sections ».
::figure set-branch-list ring=nav-branches
:::

:::step Tapez « Nom » et « Code de la section »
Dans « Nom », tapez : كرة اليد. Dans « Code de la section », tapez : HB. Le code compte de 2 à 6 lettres latines majuscules. Laissez-le vide : l'application propose un code à partir des lettres latines du nom. Si le nom n'a pas de lettres latines, l'application vous demande de taper le code.
::figure set-branch-add ring=branch-name,branch-code
:::

:::step Cliquez sur « Ajouter »
Le message « Section créée avec succès. » s'affiche. La section apparaît dans la liste sous le formulaire. L'application lui crée un coffre à elle seule, nommé « Coffre — كرة اليد ». Il vous faut le droit « Ajouter » dans « Sections ».
::figure set-branch-add ring=branch-add zoom=branch-add
:::

:::step Cliquez sur le bouton crayon de la section
Dans la ligne de la section, cliquez sur le bouton crayon. Quand vous placez la souris dessus, son nom « Modifier » apparaît. La page de la section s'ouvre. L'image montre la section « Football » comme exemple.
::figure set-branch-rows ring=branch-edit zoom=branch-edit
:::

:::step Ouvrez l'onglet « Catégories »
Cliquez sur « Catégories », à côté de « Général ». C'est là que vous ajoutez les catégories de la section. L'article « Comment ajouter une catégorie dans une section » l'explique.
::figure set-branch-detail ring=branch-tab-categories zoom=branch-tab-categories
:::

:::step Choisissez la section principale si besoin
Dans la liste des sections, cliquez sur le bouton drapeau de la section voulue. Quand vous placez la souris dessus, son nom « Définir comme section principale » apparaît. Le message « Section principale définie. » s'affiche. Vous ne voyez pas le bouton sur une section ? C'est la section principale actuelle. La section principale ne donne aucun avantage. Pour un joueur inscrit dans plusieurs sections, son inscription dans la section principale devient l'inscription de base. Et la page « Catégories » et les pages de présence s'ouvrent d'abord sur la section principale. Le bouton demande le droit « Modifier » dans « Sections ».
::figure set-branch-rows ring=branch-set-main zoom=branch-set-main
:::

:::tip
Le bouton « Membres » de chaque section affiche les joueurs qui y sont inscrits. Mais en général, vous ajoutez les joueurs depuis la page du joueur.
:::
