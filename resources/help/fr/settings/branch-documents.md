Les types de documents sont communs à toutes les sections du club. Mais vous choisissez les sections qui demandent chaque type à leurs joueurs. Ainsi, on ne demande pas à un nageur ce qui concerne le football.

:::example
La fédération de football demande « رخصة الاتحاد » (licence fédérale) chaque saison. Le club la crée et la demande seulement aux joueurs de football.
:::

:::step Ouvrez la page « Types de documents »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Types de documents » sous « Paramétrage ». Vous ne la voyez pas ? Cliquez sur « Paramétrage » pour l'afficher. Il vous faut le droit « Voir » dans « Types de documents ».
::figure set-doc-types ring=nav-document-types
:::

:::step Cliquez sur le bouton « Nouveau type de document »
En haut de la page, cliquez sur le bouton avec le signe +. Quand vous placez la souris dessus, son nom « Nouveau type de document » apparaît. Une fenêtre s'ouvre. Il vous faut le droit « Ajouter » dans « Types de documents ».
::figure set-doc-types ring=doc-add zoom=doc-add
:::

:::step Tapez le « Nom »
Dans « Nom », tapez : رخصة الاتحاد.
::figure set-doc-type-name ring=doc-name
:::

:::step Choisissez la « Validité »
Dans « Validité », choisissez « Une saison ». La licence reste valable jusqu'à la fin de la saison.
::figure set-doc-type-name ring=doc-validity
:::

:::step Laissez « Football » seul dans « Sections »
Dans la fenêtre, toutes les sections sont cochées au départ. Cliquez sur la case à côté de « Natation » pour la décocher. « Football » reste seul. Quand vous modifiez un type existant, si vous décochez une section qui a des enregistrements, l'application demande une deuxième confirmation.
::figure set-doc-type-name ring=doc-branch-1 zoom=doc-branch-1
:::

:::step Cochez « Obligatoire »
Cliquez sur la case à côté de « Obligatoire ». Le joueur qui ne le remet pas a un dossier incomplet.
::figure set-doc-type-branches ring=doc-required zoom=doc-required
:::

:::step Cliquez sur « Enregistrer »
Le message « Type de document créé. » s'affiche. Le type apparaît dans le tableau. Dans la colonne « Sections », il n'y a que « Football ».
::figure set-doc-type-form ring=doc-save zoom=doc-save
:::

:::tip
La zone « Nombre de copies » demande plusieurs exemplaires du document, par exemple 4 photos. Ensuite, le dossier du joueur compte les copies reçues.
:::
