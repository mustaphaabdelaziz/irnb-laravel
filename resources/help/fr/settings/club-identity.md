Le nom, la couleur et le logo du club apparaissent dans toute l'application et sur les documents imprimés. Vous les changez depuis la page « Paramètres ».

:::example
Le club tape ses trois noms, puis choisit la couleur « Bleu », puis envoie son logo.
:::

:::step Ouvrez la page « Paramètres »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Paramètres » sous « Système ». Vous ne la voyez pas ? Cliquez sur « Système » pour l'afficher. La page s'ouvre sur « Informations de base ». Vous ne voyez pas la page ? Il vous faut le droit « Voir » dans « Paramètres ».
::figure set-identity-basic ring=nav-settings
:::

:::step Tapez les noms du club et l'abréviation
Tapez le nom de votre club dans « 🇩🇿 اسم النادي (عربي) », puis en français et en anglais dans les deux zones voisines. Dans « Abréviation », tapez le nom abrégé, jusqu'à 20 caractères.
::figure set-identity-basic ring=settings-club-names,settings-short-name
:::

:::step Cliquez sur « Enregistrer »
Le message « Configuration mise à jour avec succès. » s'affiche. Il vous faut le droit « Modifier » dans « Paramètres ». Dans les autres zones, vous pouvez taper le « Slogan », la « Description » et la « Date de fondation ».
::figure set-identity-basic ring=settings-save zoom=settings-save
:::

:::step Ouvrez « Image de marque »
Cliquez sur ce nom dans la liste des rubriques. Elle est à côté de la page, et sur téléphone c'est une bande horizontale au-dessus. Sur téléphone, faites glisser la bande sur le côté jusqu'à voir le nom. La carte « Couleur du club » s'affiche, avec la carte du logo en dessous.
::figure set-identity-branding ring=settings-tab-branding zoom=settings-tab-branding
:::

:::step Dans « Couleur du club », cliquez sur « Bleu »
La couleur de l'application change tout de suite. Un instant après, l'application enregistre seule la couleur pour tous les utilisateurs : pas besoin de cliquer sur « Enregistrer ».
::figure set-identity-branding ring=settings-color-blue zoom=settings-color-blue
:::

:::step Choisissez le fichier du « Logo »
Cliquez sur le bouton de choix de fichier sous « Logo », puis choisissez une image. L'application accepte toute image jusqu'à 2 Mo.
::figure set-identity-logo ring=settings-logo
:::

:::step Cliquez sur « Enregistrer »
C'est le bouton « Enregistrer » sous la carte du logo. Le message « Configuration mise à jour avec succès. » s'affiche. Le logo apparaît dans le menu latéral, et la page prend la nouvelle couleur.
::figure set-identity-logo ring=settings-branding-save zoom=settings-branding-save
:::

:::tip
Le logo apparaît dans le menu latéral, sur la page de connexion, en tête des documents imprimés et dans l'onglet du navigateur. Pour une autre image dans l'onglet du navigateur, envoyez-la dans « Favicon », sous « Logo ».
:::
