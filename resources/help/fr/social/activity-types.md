Chaque activité a un type, comme « الحملات التطوعية » (campagnes de bénévolat). Chaque type est un chapitre du rapport moral, imprimé selon son numéro « # ». Les types sans activité dans la période du rapport ne sont pas imprimés.

:::example
Nous ajoutons le type « الأيام التحسيسية » (journées de sensibilisation). Puis nous lui donnons le numéro 6, pour qu'il soit imprimé juste après les cinq premiers chapitres. Le premier est « تنظيمات النادي », le dernier « إعلانات النادي ».
:::

:::step Ouvrez la page « Types d'activités »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Types d'activités » sous « Paramétrage ». Vous ne le voyez pas ? Cliquez sur « Paramétrage » pour l'afficher. Les types s'affichent dans un tableau, chacun avec son numéro sous « # ». Il y en a 11 dans l'exemple.
::figure soc-activity-types-list ring=nav-activity-types
:::

:::step Tapez le « Nom », puis cliquez sur « Ajouter »
Dans « Nom », tapez : الأيام التحسيسية. Puis cliquez sur « Ajouter ». Le message « Type ajouté » s'affiche. Le nouveau type prend le numéro qui suit le dernier, ici 12. Un nom ne peut pas se répéter. Il vous faut le droit « Ajouter » dans « Types d'activités ».
::figure soc-activity-types-add ring=atype-name,atype-add
:::

:::step Cliquez sur le bouton crayon du type
Sur la ligne du type, cliquez sur le bouton crayon. Son nom « Modifier » s'affiche quand vous passez la souris dessus. L'image montre la ligne « حملة تطوعية » comme exemple. Il vous faut le droit « Modifier » dans « Types d'activités ».
::figure soc-activity-types-rows ring=atype-edit-demo zoom=atype-edit-demo
:::

:::step Changez « # » et le nom, puis cliquez sur « Enregistrer »
Le numéro et le nom deviennent des champs sur la ligne. Dans notre exemple, tapez 6 dans le champ du numéro. Puis cliquez sur « Enregistrer » sur la ligne. Le message « Type modifié » s'affiche. Si deux numéros sont égaux, les deux types sont classés par nom. « Annuler » ferme la ligne sans rien changer. L'image montre la ligne « حملة تطوعية » comme exemple, car le nouveau type n'a pas été enregistré.
::figure soc-activity-types-edit ring=atype-order-edit,atype-name-edit,atype-save
:::

:::step Lisez la colonne « Activités »
La colonne « Activités » compte les activités de chaque type. Le bouton corbeille d'un type utilisé est pâle et ne se clique pas, tant que le nombre dans « Activités » est au-dessus de zéro.
::figure soc-activity-types-list ring=atype-count-col,atype-delete-used
:::

:::step Supprimez un type sans activité
Sur un type sans activités, comme « احتفال / مناسبة », cliquez sur le bouton corbeille. Son nom « Supprimer » s'affiche quand vous passez la souris dessus. L'application vous demande « Êtes-vous sûr ? ». Après confirmation, le message « Type supprimé » s'affiche. Il vous faut le droit « Supprimer » dans « Types d'activités ».
::figure soc-activity-types-rows ring=atype-delete-free zoom=atype-delete-free
:::

:::warning
⚠️ La suppression d'un type est définitive et ne peut pas être annulée.
:::
