Tout ce que le club fait en dehors de l'entraînement est une activité : une campagne, une formation ou la participation à un tournoi. Vous l'enregistrez une seule fois, et elle entre dans le rapport moral.

:::example
Nous enregistrons « حملة تنظيف شاطئ المدينة » (nettoyage de la plage de la ville), de type « الحملات التطوعية » (campagnes de bénévolat). Une seule journée, à « شاطئ المدينة », avec « جمعية البيئة المحلية ». Les nageurs de la catégorie « أصاغر » y ont participé.
:::

:::step Ouvrez la page « Activités »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Activités » sous « Activités sociales ». Les cartes des activités s'affichent, les plus récentes d'abord. Au-dessus : le nombre d'activités, les « Bénéficiaires » et les « Participants ».
::figure soc-record-activity-list ring=nav-activities
:::

:::step Cliquez sur « Nouvelle activité »
Le formulaire de l'activité s'ouvre. Il vous faut le droit « Ajouter » dans « Activités ». Vous ne voyez pas le bouton ? Vous n'avez pas ce droit.
::figure soc-record-activity-list ring=act-new zoom=act-new
:::

:::step Remplissez le « Titre », le « Type » et les dates
Dans « Titre », tapez : حملة تنظيف شاطئ المدينة. Choisissez le « Type », puis la « Date de début ». « Date de fin » reste vide pour une activité d'un jour, avec en dessous « Vide pour une activité d'un jour ». Pour une activité sur plusieurs jours, tapez-y le dernier jour. Sous « Date en texte », l'application indique : « Imprimée à la place de la date, ex. : le 17 de chaque mois ». Ici, ce champ reste vide.
::figure soc-record-activity-main ring=act-title,act-type,act-starts,act-ends,act-date-label
:::

:::step Remplissez le lieu, les partenaires, la section et le responsable
Dans « Lieu », tapez : شاطئ المدينة. Dans « Partenaires », tapez : جمعية البيئة المحلية. « Organisateur » et « Résultat » servent aux participations sportives. Sous « Résultat », un exemple : « Ex. : champion, finaliste ». Nous les laissons vides. Choisissez la « Section » : Natation. Sous « Catégories concernées », seules les catégories de cette section s'affichent. Cochez « أصاغر ». Puis choisissez le « Responsable » dans la liste.
::figure soc-record-activity-details ring=act-location,act-partners,act-branch,act-categories,act-responsible
:::

:::step Saisissez les participants et le coût
Dans « Bénéficiaires », tapez : 150. Dans « Bénévoles externes », tapez : 12. Dans « Coût », tapez : 8500. En dessous, ce message : « Indicatif, non comptabilisé ». Puis choisissez les joueurs dans « Joueurs participants », un par un : chacun apparaît sous forme d'étiquette. Faites de même pour les membres du bureau dans « Membres du bureau participants ».
::figure soc-record-activity-people ring=act-beneficiaries,act-external,act-cost,act-players,act-board
:::

:::step Écrivez la « Description » et le « Rapport de l'activité »
La « Description » est une phrase qui présente l'activité. Le « Rapport de l'activité » est un texte plus long. Sous « Rapport de l'activité », ce message : « Ce texte est imprimé dans le rapport moral lorsque « Ajouter les détails » est coché ».
::figure soc-record-activity-text ring=act-description,act-report,act-report-hint
:::

:::step Cliquez sur « Enregistrer »
La page de l'activité s'ouvre, et le message « Activité enregistrée » s'affiche. De là, vous ajoutez les photos et les fichiers, comme dans l'article « Comment ajouter les photos et les fichiers d'une activité ». « Annuler » vous ramène sans enregistrer.
::figure soc-record-activity-text ring=act-save zoom=act-save
::figure soc-record-activity-saved
:::

:::tip
L'activité entre dans le chapitre de son type du rapport moral si sa « Date de début » tombe dans la période du rapport. La « Date de fin », elle, ne change pas le chapitre.
:::
