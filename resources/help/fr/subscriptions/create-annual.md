L'abonnement annuel est ce que le joueur paie pour une saison complète. Il a un prix pour l'étudiant et un prix pour le travailleur.

:::example
Nous créons **اشتراك سنوي** (abonnement annuel) pour la saison **2026/2027** : 3000 DA pour l'étudiant et 5000 DA pour le travailleur, dans les sections **Football** et **Natation**. La catégorie « أشبال » est moins chère : 2500 DA pour l'étudiant et 4000 DA pour le travailleur.
:::

:::step Ouvrez la page « Abonnements »
Sur téléphone, ouvrez d'abord le menu avec le bouton ☰. Dans le menu, cliquez sur « Abonnements » sous « Gestion des joueurs ». Vous ne la voyez pas ? Cliquez sur « Gestion des joueurs » pour l'afficher.
::figure subscriptions-index ring=nav-members,nav-subscriptions
:::

:::step Cliquez sur le bouton « Ajouter un abonnement »
En haut de la page, cliquez sur le bouton avec le signe +. Quand vous placez la souris dessus, son nom « Ajouter un abonnement » apparaît. La page « Ajouter un abonnement » s'ouvre.
::figure subscriptions-index ring=subscriptions-new zoom=subscriptions-new
:::

:::step Tapez le nom et les deux prix
Sous « Type », « Cotisation annuelle » est déjà choisi. Tapez « اشتراك سنوي » dans la zone « Nom ». Laissez « Saison » telle quelle : 2026/2027. Tapez 3000 dans « Tarification étudiant », et 5000 dans « Tarification travailleur ».
::figure subscription-create ring=sub-name,sub-season,sub-prices
:::

:::step Choisissez les deux sections
Descendez un peu : tournez la molette de la souris vers vous, ou glissez deux doigts sur le pavé tactile. Sur téléphone, faites glisser l'écran vers le haut avec le doigt. Sous « Sections », cochez « Football » et « Natation ». Choisissez les sections avant les catégories : si vous les changez ensuite, certaines catégories cochées peuvent être décochées.
::figure subscription-create-branches ring=sub-branches
:::

:::step Choisissez les catégories
« Catégories » est juste sous « Sections ». Cochez chaque catégorie. Un tableau apparaît en dessous, avec une ligne par catégorie.
::figure subscription-create-categories ring=sub-categories
:::

:::step Tapez le prix de « أشبال »
Dans la ligne « أشبال », tapez 2500 sous « Tarification étudiant » et 4000 sous « Tarification travailleur ». Laissez les autres lignes vides : elles prennent les deux prix normaux.
::figure subscription-create-categories ring=sub-category-price zoom=sub-category-price
:::

:::tip
Sous les catégories, les « Statuts concernés » sont tous cochés : tout joueur peut recevoir l’abonnement, sauf ceux qui ont quitté le club. Décochez un statut (par exemple « معتزل ») pour écarter ces joueurs.
:::

:::step Cliquez sur « Enregistrer »
Le bouton est en bas de la page. Descendez-y de la même façon, puis cliquez sur « Enregistrer ». La page de l'abonnement s'affiche, avec le message « Abonnement créé avec succès. ».
::figure subscription-create-save ring=sub-save zoom=sub-save
:::

Après l'enregistrement, aucun joueur ne doit encore cet abonnement. Ajoutez-y les joueurs depuis sa page.

:::tip
L'abonnement concerne seulement les catégories cochées. Sans aucune case cochée, il concerne toutes les catégories avec un seul prix. Et sans aucune section, il concerne tout le club.
:::

:::warning
Un nom d'abonnement ne peut pas se répéter dans la même saison. Si le nom est déjà utilisé, l'abonnement n'est pas enregistré et un message rouge s'affiche sous « Nom ».
:::
